**Don't like Google's AI answers? Here's how to get rid of them**
Google Search has introduced AI Overviews—AI-generated summaries at the top of search results—to provide quick, conversational-style answers similar to those from chatbots like ChatGPT. While these summaries aim to streamline information retrieval, they are not always accurate. Users who prefer traditional search results without AI summaries have several options: (1) Append the parameter 'noai' to any search query (e.g., 'best carbon steel pans noai'), which Google still respects as of January 19, 2026; (2) Install the open-source 'Hide Google AI Overviews' browser extension from the Chrome Web Store to automatically remove AI Overviews; (3) Create a custom Google search shortcut in Chrome by setting a query string with the 'noai' parameter via Settings > Search engine > Manage search engines; (4) Switch to privacy-focused search engines like DuckDuckGo, Ecosia, or Brave Search, which either disable AI features by default or require explicit opt-in. Unlike most engines that rely on Bing or Yandex results, Brave Search maintains its own search index.
